# aportekila.github.io

[![Deploy site](https://github.com/aportekila/aportekila.github.io/actions/workflows/deploy.yml/badge.svg)](https://github.com/aportekila/aportekila.github.io/actions/workflows/deploy.yml)

Source code for [Abdullah Akgül](https://aportekila.github.io)'s personal academic site — a postdoctoral researcher's portfolio covering publications, projects, and CV in reinforcement learning and probabilistic machine learning.

## Stack

Built with [Jekyll](https://jekyllrb.com/) on the [al-folio](https://github.com/alshedivat/al-folio) theme, hosted on [GitHub Pages](https://pages.github.com/). Content lives in `_pages/`, `_projects/`, `_news/`, and `_bibliography/papers.bib`; site-wide settings are in [_config.yml](_config.yml).

## Local development

For local setup, build, and deployment details, see [INSTALL.md](INSTALL.md). For theme customization options (layouts, collections, third-party libraries), see [CUSTOMIZE.md](CUSTOMIZE.md).
